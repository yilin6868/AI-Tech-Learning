# 每日笔记

这里用于保存每天筛选、试用和深入分析的 AI 技术项目。

## 文件命名

建议按年份和月份建立子目录，并使用日期命名：

```text
daily/2026/10/2026-10-07.md
```

## 使用方法

1. 复制 [每日笔记模板](../templates/daily-note-template.md)。
2. 将文件保存到对应年份和月份目录。
3. 每天先广泛浏览候选项目，但只选择 1 个进行深度研究。
4. 至少完成“理解原理、设计实验、实际试用、记录问题、形成判断”五个环节。
5. 明确区分官方说明、个人理解和实验事实，不为了完成日报而编造结论。
6. 周末将本周最有价值的结论整理到 `weekly/`。
